To use this feature, you must use the preview version of the Office JavaScript API library from the [Office.js content delivery network (CDN)](https://officeapis.public.onecdn.static.microsoft/beta/office.js). The [type definition file](https://officeapis.public.onecdn.static.microsoft/beta/office.d.ts) for TypeScript compilation and IntelliSense is found at the CDN and [DefinitelyTyped](https://raw.githubusercontent.com/DefinitelyTyped/DefinitelyTyped/master/types/office-js-preview/index.d.ts). You can install these types with `npm install --save-dev @types/office-js-preview`.
